# HackTheBox - WriteUps

A collection of my writeups for [HackTheBox](https://www.hackthebox.com/) machines and challenges, written along my progress towards the **CPTS** certification and the competitive seasons.

Each writeup covers the full methodology: enumeration, exploitation, lateral movement and privilege escalation, with the commands used and accompanying screenshots.

Each machine has its own folder containing the writeup (`MachineName.md`) and an `Images/` subfolder with the screenshots.

## Disclaimer

This repository only contains writeups for **retired** HackTheBox machines, or ones whose disclosure is explicitly allowed. They are published for educational purposes, as part of a learning process in penetration testing / offensive security. Writeups for currently active machines are kept private and added here once the box is retired. Please don't use these to cheat on active machines.
